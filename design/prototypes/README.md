# HTML 原型

每个原型使用独立目录：

```text
prototypes/<prototype-id>/
├── README.md
├── index.html
├── styles.css
├── app.js
└── assets/
```

原型必须说明启动方式、覆盖的用户故事、可交互状态和已知限制。

---

## 当前原型：巴食 · AI 食谱 高保真原型 v0

本目录下的 `index.html` + `prototype.css` + `app.js` 即为完整原型（DESIGN-001 ~ DESIGN-004 合辑）。

### 启动方式

无需任何依赖与构建，直接双击 `index.html` 用浏览器打开即可（完全离线，无 CDN / 无网络请求）。
也可用任意静态服务启动，例如 `npx serve .`。

### 视觉方向

- 像素风 × 现代：位图像素图标与食物封面（SVG crispEdges 渲染）、4px 硬边投影、抖动纹理、等宽字体像素标签；布局保持现代卡片化。
- 低饱和绿色主调：主色 `#5F8F6E`，全局降饱和，厨房场景长时间使用不疲劳。
- 颜色不是唯一状态提示：所有状态（低置信度 / 待启用 / 失败）均带图标 + 文字标签。

### 已知限制（原型边界）

- 登录、真实解析、云同步为演示提示，未接入后端。
- 拖拽排序以拖柄图标占位，未实现真实拖拽。
- 横屏与平板双栏未覆盖；按 390px 竖屏基线设计。
- 回收站、隐私设置、数据导出（P1）为入口示意。
