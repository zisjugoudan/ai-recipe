# UI-016c 下厨扣减确认面板

- 所属模块：DESIGN-005 冰箱与推荐
- 关联：US-011（下厨后扣减库存）
- 目标：烹饪完成后，确认从冰箱扣除本次用掉的食材批次。

## 功能清单

1. **触发**：烹饪模式走完最后一步「全部完成」自动流转到此面板（闭环：库存→推荐→烹饪→扣减）。
2. **预计消耗列表**（每项一行）：
   - 食材名 + 预计用量。
   - 默认选中扣减；可**逐项取消勾选**（行变灰，不扣减）。
   - 可**改数量**（输入框）。
   - 可**换批次**（下拉选择；如番茄默认选 08-06 临期批次，优先清库存）。
3. **数量待确认提示**：如「冰糖：数量未知，请确认用量」。
4. **主按钮「确认并更新冰箱」**：按勾选项扣减批次，回冰箱库存。
5. **次按钮「暂不更新」**：本次不扣减，关闭面板。
6. **过期 / 缺失处理**：过期批次不参与；数量为未知时要求用户确认用量。

## 页面结构

- 顶部：标题「扣减确认」+ 说明「本次烹饪预计消耗」。
- 内容区：消耗项列表（勾选 / 数量 / 批次）。
- 底部固定栏：确认并更新（主）/ 暂不更新（次）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 全部勾选，默认到期更早批次 |
| 用户取消某项 | 行变灰，不扣减 |
| 数量未知 | 提示确认用量 |
| 批次可选 | 下拉切换 |

## 走查要点

- 这是库存闭环的最后一环，扣减前必须逐项可改、可取消。
- 默认选临期批次，体现「优先清库存」产品目标。
- 数量未知项不能静默扣减，必须显式确认。
