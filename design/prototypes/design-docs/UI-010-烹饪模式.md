# UI-010 烹饪模式

- 所属模块：DESIGN-004 烹饪模式
- 关联：US-010（引导式烹饪、多计时器）
- 目标：在厨房场景下大字号、防误触地引导逐步烹饪，支持多计时器并存。

## 功能清单

1. **深绿厨房态**：整体深色玻璃质感面板，高对比大字，适合厨房远看。
2. **步骤卡**：当前步骤（序号 / 操作 / 火候 / 时间 / 关联食材），切换步骤卡片滑入动效。
3. **上一步 / 下一步**：切换步骤；最后一步「下一步」触发「全部完成」→ 自动流转到库存扣减确认（UI-016c）。
4. **多计时器并存**：可同时跑多个（如煮汤 20 分钟 + 焯水 3 分钟），各可启动 / 暂停 / 加时。
5. **计时结束提醒**：倒计时归零时像素闪烁 + 声音提示（原型为闪烁）。
6. **防误触退出**：返回键轻量化（透明幽灵按钮，无描边无底色，65% 透明，hover 才实）；点退出弹「是否退出烹饪模式」二次确认。
7. **当前步骤关联食材**：展示本步需要的食材，便于备料。

## 页面结构

- 顶部：退出按钮（轻量幽灵）+ 步骤进度（STEP X / N）+ 当前火候图标。
- 中部：步骤卡（大字号操作 + 火候 + 时间 + 关联食材 chips）。
- 底部：计时器区（可多个）+ 上一步 / 下一步。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 进行中 | 当前步骤 + 活动计时器 |
| 多计时器 | 并存，可分别暂停 |
| 计时结束 | 闪烁提醒 |
| 退出 | 二次确认 |
| 全部完成 | 自动进扣减确认 |

## 走查要点

- 退出按钮要「轻」（用户反馈），不要做成显眼实心按钮。
- 大字号是核心，步骤卡最小高度保证短步骤不缩成一条。
- 多计时器并存必须有视觉区分（颜色 / 位置），避免混淆。
