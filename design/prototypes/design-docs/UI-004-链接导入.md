# UI-004 链接 / 内容导入页

- 所属模块：DESIGN-001 链接导入全流程
- 关联：US-004、US-005
- 目标：让用户输入来源，并在开始解析前清楚知道会用到哪些能力。

## 功能清单

1. **来源输入区**：
   - 链接输入框（必填）：粘贴小红书 / 抖音等公开链接。
   - 来源平台自动识别标签：识别后显示「小红书 / 抖音 / 未知平台」徽标。
   - 可选备注、目标分类选择。
2. **能力路线提示**：展示本次会用到的能力路线——自定义 LLM、本地 OCR、云 OCR、托管 AI 等，让用户有预期。
3. **主按钮「开始解析」**：进入解析进度页（UI-005）。
4. **次按钮「改为手动创建」**：跳编辑页从零创建。
5. **能力不可用提示**（按场景）：
   - 游客未配置 LLM API → 引导去 LLM 设置，也可改手动创建。
   - 本地 OCR 未安装 → 引导安装插件 / 模型，或选云 OCR / 手动粘贴文本。
   - 登录用户额度不足 → 显示额度不足，提供自定义 API 或手动创建替代。
   - 禁止上传图片 → 不显示诱导上传云 OCR 文案，只提示本地 OCR 或手动录入。

## 页面结构

- 顶部：标题「导入链接」+ 返回。
- 内容区：输入框 + 平台识别标签 + 备注 / 分类 + 能力路线提示条。
- 底部：主按钮「开始解析」、次按钮「改为手动创建」。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 可输入，能力路线正常显示 |
| 平台识别中 | 输入框下方显示识别中（加载动效） |
| 能力缺失 | 对应提示条 + 引导按钮 |
| 离线 | 登录 / 云能力不可用，提示用本地 / 手动 |

## 走查要点

- 开始解析前必须让用户看到「会用到什么能力」，禁止黑盒。
- 「改为手动创建」是兜底路径，永远可达。
- 输入框聚焦时显示像素下划线（与编辑页统一语言）。
