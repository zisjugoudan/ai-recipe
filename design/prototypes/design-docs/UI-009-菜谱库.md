# UI-009 菜谱库 / 分类 / 搜索

- 所属模块：DESIGN-002 首页与菜谱管理
- 关联：US-009（长期管理）
- 目标：让用户管理长期积累的菜谱，支持搜索、分类、收藏、回收站。

## 功能清单

1. **搜索框**：实时过滤菜谱（输入即过滤，不需回车）；支持菜名 / 食材 / 标签。
2. **分类筛选**：分类标签（家常 / 早餐 / 汤羹 / 烘焙…）+ 排序（最近 / 耗时 / 难度）。
3. **菜谱网格 / 列表**：位图封面卡 + 菜名 + 耗时 / 难度 / 份量 + 来源徽标 + 收藏心。
4. **收藏入口**：可切到「仅看收藏」。
5. **回收站入口**：二级页，展示已删除菜谱，可恢复或二次确认后彻底删除。
6. **点击菜谱卡**：进详情页（UI-007）。

## 页面结构

- 顶部：标题「菜谱库」+ 搜索框。
- 内容区：分类 chips（横向滚动）+ 排序 + 菜谱卡网格。
- 底部：主 Tab 栏（菜谱库高亮）+ 右下 FAB（添加菜谱）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 全部菜谱网格 |
| 空 | 引导去导入 / 创建 |
| 搜索无结果 | 提示「没有匹配的菜谱」 |
| 仅收藏且无收藏 | 空态引导 |
| 极限 | 分类过多横向滚动 /「更多分类」 |

## 走查要点

- 搜索必须实时过滤（原型已验证交互）。
- 卡片封面位图风格；来源徽标（小红书 / 抖音）前置展示。
- FAB 在菜谱库页为「添加菜谱」，点进添加入口。
