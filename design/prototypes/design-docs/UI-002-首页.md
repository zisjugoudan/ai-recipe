# UI-002 首页

- 所属模块：DESIGN-002 首页与菜谱管理
- 关联：US-009（最近菜谱、常用分类、继续烹饪）、US-004（全局导入入口）
- 目标：让用户快速导入菜谱、继续查看最近菜谱与未完成任务。

## 功能清单（默认态）

1. **顶部状态条（左文右签，视觉平衡）**：左侧问候语（如「晚上好，今天吃什么？」+ 日期）+ 右侧「游客 · GUEST」小标签（点击进「我的」）。**不放大头像**，避免右上角视觉失衡。
2. **进度条（若有待处理任务）**：显示「解析进度 52%」类信息，点击进解析进度页。
3. **快速导入卡片**：入口聚合——粘贴链接、从剪贴板导入、拍照 / 选图、手动创建（4 个入口）。
4. **继续处理入口**：若存在未完成导入任务，显示「继续处理」卡片，点击进解析进度页。
5. **最近菜谱**：最近查看 / 导入的菜谱卡（位图封面 + 菜名 + 份量 / 耗时 + 来源徽标 + 收藏）。
6. **分类快捷入口**：横向分类标签（如 早餐 / 家常 / 汤羹 / 烘焙…），点击进菜谱库并带筛选。
7. **收藏入口**：快捷进入收藏列表。
8. **全局 FAB**：首页右下角悬浮「+」添加按钮（点击进添加入口）；快速导入卡片与 FAB 二选一可达，不重复堆叠。

## 功能清单（空状态）

- 标题「还没有菜谱」。
- 说明「粘贴小红书 / 抖音链接，或手动创建第一道菜」。
- 主按钮「导入菜谱」（进添加入口）；次按钮「手动创建」（进编辑页新建）。
- 空状态碗图标轻微浮动动效。

## 页面结构

- 顶部：状态条。
- 内容区：进度卡（按需）→ 快速导入卡 → 继续处理（按需）→ 最近菜谱 → 分类快捷 → 收藏。
- 底部：主 Tab 栏（首页高亮）+ 右下 FAB。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 有菜谱，展示最近与分类 |
| 空 | 引导导入 / 手动创建 |
| 有未完成导入 | 顶部进度卡 + 继续处理入口 |
| 极限 | 菜名超长最多 2 行；图片缺失用占位卡 |
| 游客 | 右上角「游客」标签 |

## 走查要点

- 头部「游客」标签用小字号胶囊，不要做成大头像。
- 快速导入卡的 4 入口用图标网格，避免一整列按钮。
- 菜谱卡封面用位图风格；热菜（如番茄牛腩）封面带蒸汽动效。
