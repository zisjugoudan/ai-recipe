# UI-014 冰箱库存（分区冰箱）

- 所属模块：DESIGN-005 冰箱与推荐
- 关联：US-011（库存批次）、US-012（临期筛选）、US-013（按食材推荐）
- 目标：以「轻拟物分区冰箱」呈现库存批次，支持筛选、展开批次、区内新增。

## 功能清单（默认态 · 分区冰箱）

1. **二级切换**：库存 / 推荐（推荐进 UI-016）。
2. **我的冰箱（轻拟物冰箱）**：浅冷色箱体 + 顶部箱门虚线缝；内部分四个分区卡：
   - **冷藏区（层架）**：食材 chip 底部带 3px 层板投影，像摆在玻璃层板上。
   - **冷冻区（抽屉）**：冷色背景 + 底部凹槽把手。
   - **常温区（米面粮油）**：冰糖（数量未知）、大米等。
   - **其他区（待整理）**：空分区，虚线框 +「放入这个区域」按钮。
3. **分区可展开 / 收起**，区头部有「区内新增」按钮（点击进批次编辑，默认跟随该分区）。
4. **摘要四卡**：可用批次 / 临期 / 已过期 / 数量未知。
5. **临期提醒**：如「牛奶、番茄（1 批次）即将过期」。
6. **8 项快捷筛选**：全部 / 临期 / 已过期 / 冷藏 / 冷冻 / 常温 / 数量未知 / 未设置日期——筛选时**空分区自动隐藏**。
7. **食材 chip（同名聚合）**：如番茄聚合 2 批次，点 chip 就地展开批次行（编辑 / 标记用完 / 标记丢弃）。
8. **五种状态徽标**：正常 / 临期 / 已过期 / 未设置日期 / 数量未知（均带图标 + 文字）。
9. **批次操作**：编辑（进 UI-015）、标记用完、标记丢弃（**二次确认**，文案说明只影响当前批次）。
10. **过期食材**：标注「不参与推荐匹配」（如过期鸡蛋）。
11. **右下 FAB**：冰箱页变为「添加食材」。

## 功能清单（空状态）

- 冰箱为空时展示空状态：引导「添加第一样食材」，点击进批次编辑。

## 页面结构

- 顶部：二级切换 + 摘要四卡 + 临期提醒。
- 内容区：筛选 chips（横向）→ 分区冰箱（4 区，可展开）。
- 底部：FAB「添加食材」（非 Tab）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 四分区有食材 |
| 空 | 空冰箱引导 |
| 筛选 | 空分区自动隐藏，无结果提示 |
| 过期 | 标注不参与推荐 |
| 数量未知 | 明确标注，不写 0 |

## 走查要点

- 分区冰箱是视觉核心：冷藏=层架感、冷冻=抽屉、常温=米面粮油，世界观统一。
- 同名食材必须聚合，展开才显示批次，避免列表爆炸。
- 五种状态徽标图标 + 文字，不能只靠颜色。
- 丢弃 / 用完等破坏性操作必须二次确认，且说明「只影响当前批次」。
