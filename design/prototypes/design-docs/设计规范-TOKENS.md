# 设计规范 / 像素语法（设计系统页）

- 用途：设计系统沉淀页，集中展示颜色、字体、组件、像素语法、动效，供设计师与开发对齐。
- 注：此为原型内置的「设计规范」展示页，不是外部独立文档；产品名 / 规范以 `UI_HANDOFF.md` 与 `prototype.css` 变量为准。

## 内容模块

1. **色板（低饱和绿色主调）**
   - 主色 `#5F8F6E`（青灰绿）；纸面底色 `#F2EFE7`；墨色偏绿深灰。
   - 辅助色全部降饱和：琥珀（临期）、红（过期 / 失败）、蓝灰（缺 2 样 / 可补选）。
   - 标注「颜色不是唯一状态提示」，状态必带图标 + 文字。

2. **字体**
   - 正文无衬线；像素标签 / 计数用等宽字体（如英文眉题、STAGE 4/6 类标签）。

3. **组件**
   - 卡片、按钮（缺角 + 硬边投影）、输入框（聚焦像素下划线）、徽标（来源 / 置信度 / 状态）、开关（方形滑块 + 阶梯动画）、进度条（缺角 + 斜纹）、Tab 栏（胶囊激活态）。

4. **像素语法**
   - 位图食物封面（SVG crispEdges，放大不糊）。
   - 硬边投影 4px（跟随缺角用 `filter: drop-shadow`）。
   - 抖动纹理（dither）。
   - 像素虚线分隔（状态栏 / 导航 / Tab / 底栏 / 侧栏，真像素点线非 CSS dashed）。
   - 像素方块分区标题（小绿方块 + 2px 偏移硬投影）。
   - 阶梯缺角三档（卡片 8px 双阶梯 / 按钮输入 4px / 徽标 3px）。

5. **动效（像素逐帧，全部 steps 缓动，尊重减弱动态）**
   - 热菜蒸汽（封面飘起）。
   - PRESS START / 闪烁（欢迎页、加载省略号）。
   - 浮动（Logo、空状态碗）。
   - 斜纹流动（进度条）。
   - 弹跳 px-pop（收藏、Tab 图标、按钮点击）。
   - 屏幕进入（切屏右侧阶梯滑入）。

## 走查要点

- 设计师出图时严格遵循色板饱和度（不高于原型），保证长期不疲劳。
- 缺角只保留在特征元素（按钮 / 面板 / 徽标 / 食物封面 / 进度条 / 开关），列表行 / chip / 导航保持平直，形成节奏对比。
- 动效一律逐帧，禁止平滑过渡冒充像素风。
