# UI-007 菜谱详情页

- 所属模块：DESIGN-002 首页与菜谱管理
- 关联：US-009、US-010（开始烹饪）
- 目标：清晰展示一个已保存菜谱，支持开始做菜。

## 功能清单

1. **封面图**：位图风格封面（热菜带蒸汽动效）；缺失时用占位卡。
2. **菜名 + 收藏 + 更多操作**（更多：编辑 / 复制 / 删除 / 移动分类）。
3. **元信息**：分类、标签、份量、总耗时、难度。
4. **来源信息**：平台、原链接、导入时间。
5. **食材列表**：食材名、用量、备注。
6. **操作步骤**：步骤序号、操作、火候、时间、关联食材。
7. **备注 / 小贴士**。
8. **底部主按钮「开始烹饪」**：进烹饪模式（UI-010）。
9. **次操作**：编辑（进 UI-008）、复制、删除、移动分类。

## 页面结构

- 顶部：封面（满宽，底部像素分隔线）+ 返回 / 收藏 / 更多（右上角轻量按钮）。
- 内容区：菜名 + 元信息 + 来源 + 食材 + 步骤 + 备注。
- 底部固定栏：主按钮「开始烹饪」+ 次按钮「编辑」。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 食材 / 步骤分区明确 |
| 图片缺失 | 占位卡，不影响阅读 |
| 超长步骤 | 可展开 / 收起或自然滚动 |
| 已删除 | 不在列表，回收站可恢复 |
| 离线 | 已保存菜谱可完整查看 |

## 走查要点

- 封面与内容区用像素分隔线区分，不靠粗描边。
- 开始烹饪是主按钮，编辑是次按钮，主次分明。
- 来源信息用小字 + 图标，不与菜名争夺视觉。
