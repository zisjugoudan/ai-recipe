# UI-016 选择食材推荐

- 所属模块：DESIGN-005 冰箱与推荐
- 关联：US-013（按食材推荐本地菜谱）
- 目标：让用户选择冰箱里有哪些食材，本地确定性规则推荐「现在能做什么、缺什么」。

## 功能清单

1. **二级切换**：库存 / 推荐（库存进 UI-014）。
2. **选择区**：按分区（冷藏 / 冷冻 / 常温）点选食材 chip，多选；选中变绿带 ✓。
   - 过期食材置灰不可选（如过期菠菜）。
3. **快捷选择**：全部 / 临期优先 / 冷藏区 / 清空选择。
4. **底部 CTA（实时计数）**：
   - 有选中：显示「用已选食材推荐（N）」。
   - 一个都没选：变成「一键用全部库存推荐」。
5. **结果分组**（按缺失数量确定性分组）：
   - **已具备 · 现在就能做**（绿）：匹配 5/5 等，推荐原因「主要食材全部有库存」。
   - **缺 1 样**（琥珀）：列出缺失项，可「加入购物清单」。
   - **缺 2 样**（蓝）：同上。
   - **优先清库存**（红）：优先消耗临期食材的菜（如糖拌番茄耗临期番茄）。
   - **更多缺失**（折叠）：缺 3 样以上折叠进「更多缺失」。
6. **推荐卡片标注三类**（图标 + 文字，不止颜色）：
   - **已选命中**（绿）：所选食材正好够。
   - **冰箱已有 · 可补选**（蓝）：菜需要但该食材你冰箱有、当前未选（如只选番茄时番茄炒蛋里的鸡蛋）。
   - **缺失**（琥珀）：需要但你没有。
7. **数量待确认提示**：如「冰糖：有该食材，数量是否足够需确认」。
8. **AI 生成独立入口**：由自定义 LLM 生成，结果进草稿确认页，**不自动保存，不与本地推荐混排**。
9. **加入购物清单**：缺失食材一键加入（按名称 + 单位尝试合并）。

## 页面结构

- 顶部：二级切换 + 说明「只匹配本地正式菜谱，确定性离线规则」。
- 内容区：选择区（分区 chips）→ 结果分组（各分组卡片）。
- 底部固定 CTA：实时计数 + 触发推荐。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 未选 | CTA 变「一键用全部库存」 |
| 已选 | CTA 显示计数 N |
| 缺货 | 推荐可加购物清单 |
| 无匹配 | 提示 + AI 生成入口 |

## 走查要点

- 推荐是**确定性离线规则**，不依赖网络 / LLM，与 AI 生成入口分离。
- 三组标注（已选命中 / 冰箱已有可补选 / 缺失）必须图标 + 文字，不能只靠颜色。
- 分组头需要设计感（见 `UI-016b-推荐分组方案对比.md` 的 4 个方案）。
- 数量未知食材参与匹配时，必须提示「数量是否足够需确认」。
