## 通用说明（所有页面适用）

- **状态覆盖**：每个核心页至少考虑 默认 / 空 / 加载 / 成功 / 错误 / 弱网离线 / 游客 / 登录 八态。
- **状态提示不止颜色**：低置信、待启用、失败、临期一律带图标 + 文字标签。
- **离开二次确认**：导入草稿未保存、编辑菜谱未保存、删除菜谱，离开前必须确认。
- **离开保护**：烹饪模式避免误触返回，返回时提示是否退出。
- **游客能力差异**：游客可用本地菜谱、自定义 LLM、本地 OCR；不可用云同步与平台托管 AI。不可用能力必须说明原因与替代方案。
