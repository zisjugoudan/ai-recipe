# UI-005 解析进度页

- 所属模块：DESIGN-001 链接导入全流程
- 关联：US-005（解析过程可视化）
- 目标：让用户理解 AI 导入是分阶段处理、没有卡住。

## 功能清单（进行中 → 成功）

1. **阶段列表 / 整体进度条**：展示解析阶段，至少含文案，不只百分比。
2. **当前阶段说明**：显示当前阶段的中文说明（见下表），并配像素加载动效（4 方块跳跃 loader + 斜纹流动进度条）。
3. **阶段动画**：当前阶段点闪烁、描述文字后「···」逐帧循环，强调「正在处理」。
4. **进度自动推进**：演示中分阶段自动推进，最终到「解析完成，请确认后保存」并自动跳草稿确认页（UI-006）。
5. **取消按钮**：提供「取消」，取消后返回添加页并保留原链接。
6. **长任务可离开**：允许离开页面，首页显示「未完成任务」入口（继续处理）。

建议阶段文案：

| 阶段 | 文案 |
|---|---|
| queued | 已加入解析队列 |
| fetching | 正在获取公开内容 |
| extracting | 正在整理正文、图片和视频信息 |
| ocr | 正在识别图片中的文字 |
| asr | 正在识别视频 / 音频中的口播 |
| generating | 正在生成结构化菜谱 |
| validating | 正在检查结果格式 |
| readyForReview | 解析完成，请确认后保存 |
| failed | 解析失败，可选择降级方式继续 |
| cancelled | 已取消解析 |

## 功能清单（失败 · 降级路径）

1. **失败提示**：明确「解析失败」，文案友好，不技术化恐吓。
2. **保留原链接**：失败页仍展示原链接，便于重试。
3. **5 条降级路径**（按钮 / 列表）：
   - 粘贴正文继续
   - 上传截图继续
   - 上传视频继续
   - 手动创建菜谱
   - 稍后重试
4. 每条降级路径对应一种能力缺失或失败原因，给用户可继续的方式。

## 页面结构

- 顶部：标题「解析中」+ 取消。
- 内容区：阶段列表（当前阶段高亮 + 闪烁）+ 进度条（斜纹流动）+ 像素 loader + 当前阶段说明。
- 失败态：替换为失败提示 + 原链接 + 5 条降级路径。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 进行中 | 阶段动画 + 进度条 + loader |
| 成功 | 自动跳草稿确认 |
| 失败 | 降级路径页 |
| 取消 | 返回添加页，保留链接 |

## 走查要点

- 必须有像素化等待动效（跳跃方块 / 斜纹流动），不可用普通 spinner。
- 失败页的 5 条降级路径必须全部可达，且与原链接保留联动。
- 阶段文案用中文 + 图标，不止百分比。
