# UI-013 OCR 设置

- 所属模块：DESIGN-003 设置
- 关联：US-007（本地 OCR）、US-008（模型下载）
- 目标：管理本地 OCR 能力与模型，如实展示「识别能力待启用」，不误标可用。

## 功能清单

1. **本地 OCR 状态**：
   - 「运行时验证中」：首次打开显示验证中（加载动效）。
   - 「识别能力待启用」：未安装 / 未验证时如实展示，**不误标为可用**。
2. **模型下载**：
   - 提供模型下载入口，下载进度条（流动斜纹）展示。
   - 支持「取消下载」。
3. **云 OCR / 插件状态**：说明云端 / 插件选项与差异（按架构文档）。
4. **禁止上传图片时**：不显示诱导上传云 OCR 的文案，只提示本地 OCR 或手动录入。
5. **能力引导**：本地 OCR 未安装时引导安装插件 / 模型。

## 页面结构

- 顶部：标题「OCR 设置」+ 返回。
- 内容区：本地 OCR 状态条 → 模型下载（进度 / 取消）→ 说明。
- 底部：无主按钮（开关 / 下载为主）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 验证中 | 加载动效 + 文案 |
| 待启用 | 如实说明，不误标可用 |
| 下载中 | 流动斜纹进度 + 取消 |
| 已就绪 | 显示可用 + 识别语言等 |

## 走查要点

- 核心是「诚实」：未就绪绝不可显示成「可用」。
- 下载进度条用斜纹流动像素动效。
- 禁止上传图片的场景下，UI 不诱导云 OCR。
