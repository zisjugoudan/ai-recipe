# UI-011 我的 / 设置

- 所属模块：DESIGN-003 设置
- 关联：US-006（登录 / 同步）、US-011 / US-012 / US-013（设置入口）
- 目标：游客态与登录态的设置中心，承载登录、购物清单、LLM / OCR 设置、隐私与数据。

## 功能清单

1. **顶部身份区**：游客态显示「游客」+ 登录入口；登录态显示头像 / 昵称（原型按游客态设计）。
2. **登录 / 注册入口**：进入登录流程（演示提示）。
3. **云同步差异说明**：说明游客与登录用户的能力差异。
4. **购物清单**：二级页入口（缺食材加入后在此查看）。
5. **LLM API 设置**：进 UI-012。
6. **OCR 设置**：进 UI-013。
7. **隐私与上传设置**：禁止图片上传开关等。
8. **数据管理**：导出、回收站入口（P1，原型为示意）。

## 页面结构

- 顶部：身份区（游客 / 登录）。
- 内容区：登录卡 → 设置分组（购物清单 / LLM / OCR / 隐私 / 数据）。
- 底部：主 Tab 栏（我的高亮）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 游客 | 显示游客态 + 登录入口 + 能力差异说明 |
| 登录 | 显示账号信息 + 云同步状态 |
| 离线 | 本地设置可用，云能力提示不可用 |

## 走查要点

- 设置项分组清晰，图标 + 标题 + 右箭头。
- 游客态必须明示哪些不可用及原因（不要藏着）。
- 隐私开关用像素化开关（方形滑块 + 阶梯动画）。
