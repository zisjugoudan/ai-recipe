# UI-015 库存批次新增 / 编辑

- 所属模块：DESIGN-005 冰箱与推荐
- 关联：US-011（批次管理）
- 目标：新增或编辑一个库存批次，存放位置跟随分区入口。

## 功能清单

1. **名称（必填）**：食材名输入框。
2. **数量 + 单位**：数量可空；数量为空时明确说明「保存为『数量未知』，不写 0」。
3. **分类**：食材分类选择。
4. **存放位置**：选项为 冷藏区 / 冷冻区 / 常温区 / 其他区（默认跟随你点击添加时所在的分区）。
5. **购买日期 / 到期日期**：日期选择；到期驱动临期 / 过期状态。
6. **备注**。
7. **同名批次提示**：输入「番茄 / 鸡蛋」等同名食材时，弹提示「将新增批次，不会合并」（明确是新增批次，非覆盖）。
8. **保存**：保存后回冰箱库存（UI-014），对应分区展开该食材。
9. **删除批次**（编辑态）：二次确认。

## 页面结构

- 顶部：标题「新增 / 编辑批次」+ 返回（未保存离开确认）+ 保存。
- 内容区：各字段行（标签 + 输入）；存放位置用 chips 选择。
- 底部：保存（主）/ 删除（次，编辑态）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 全字段可填 |
| 名称为空 | 保存拦截，提示必填 |
| 数量为空 | 提示将存为「数量未知」 |
| 同名 | 提示新增批次不合并 |
| 未保存离开 | 二次确认 |

## 走查要点

- 数量为空 ≠ 0，必须显式标「数量未知」。
- 同名提示是防混淆关键点：明确「新增批次，不合并」。
- 存放位置 chips 跟随入口分区，减少用户选择成本。
