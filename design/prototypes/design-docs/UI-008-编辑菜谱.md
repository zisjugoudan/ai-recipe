# UI-008 编辑菜谱页

- 所属模块：DESIGN-002 首页与菜谱管理
- 关联：US-005（修正 AI 结果）、US-009（从零创建）
- 目标：用户手动修正 AI 结果，或从零创建菜谱。

## 功能清单

1. **编辑字段**：菜名、封面图、分类、标签、份量、总耗时、难度、来源链接、备注。
2. **食材列表**：增 / 删 / 改 / 排序；每行食材名 + 用量（食材名与用量之间细竖线分隔，**行内输入框无嵌套边框**，聚焦显示像素下划线）。
3. **步骤列表**：增 / 删 / 改 / 排序；每步可填时间、火候、备注。
4. **新增 / 删除行**：按钮增删，删除有轻量确认。
5. **拖拽 / 上下移动**：拖柄图标占位（原型未实现真实拖拽，设计需实现上下移动）。
6. **未保存离开二次确认**：有改动离开时弹确认（保留「放弃 / 保存 / 继续编辑」）。
7. **保存**：保存失败不能丢失已输入内容。
8. **手动创建不依赖 AI**：从零创建时无需任何 AI 能力。

## 页面结构

- 顶部：标题「编辑菜谱」+ 返回（返回触发未保存确认）+ 保存按钮。
- 内容区：基础字段 → 食材（可增删行）→ 步骤（可增删行）→ 备注 / 来源。
- 行内输入框：透明底融于行容器，聚焦像素下划线。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 可编辑，未保存提示机制 |
| 有改动离开 | 二次确认 |
| 保存失败 | 保留已输入内容 |
| 手动创建 | 无需 AI |

## 走查要点

- 行内输入框**不要做框中框**（用户明确反馈），聚焦用 2px 绿色像素下划线。
- 增删行按钮要明显，步骤可折叠以省空间。
- 未保存离开确认是强制项，不能跳。
