# UI-001 欢迎页 / 会话入口

- 所属模块：会话与登录
- 关联：US-001（首次进入）、游客 / 登录能力差异、UI-WELCOME-001
- 目标：让用户先建立「巴食」品牌认知，再理解可登录或以游客身份直接进入；视觉参考以项目负责人 2026-08-11 提供的红框区域为准。
- 本地参考图：design/assets/欢迎页顶部参考-2026-08-11.png。

## 功能清单

1. **品牌视觉区**：顶部由漂浮食材小元素、自绘像素字「巴食」、小字「拾味 · AI 菜谱」、主插画和说明气泡组成。
2. **漂浮元素自适应**：厨师帽、胡萝卜、番茄、辣椒、叶子的尺寸、位置与浮动幅度都依据视觉区可用宽度按比例计算；不得使用绑定某一手机分辨率的绝对屏幕坐标。超窄设备需保持元素不裁切、不遮住「巴食」。
3. **品牌字**：「巴食」使用项目内置的 Fusion Pixel 像素字体（OFL-1.1 可商用，支持简体中文）以 `Text` 渲染，替代原手工点阵绘制与生成动画；保留深绿色主体与右下立体阴影，不使用系统中文字形。
4. **主插画相框**：使用 `assets/welcome/cover.png`，外框采用参考图的像素立体层次：右下投影、深绿外轮廓、浅色框带、上左高光、下右压暗、内侧深绿压边；框厚随容器宽度小范围缩放。
5. **说明气泡**：放在插画下方并与插画建立视觉连接，文字为「把小红书 / 抖音上的菜谱，收进你的口袋厨房」，保留像素轮廓与红色爱心装饰。
6. **三条特性行**：链接导入 / 自带 AI / 隐私优先，每条带图标、标题和一句说明。
7. **主按钮「登录 / 注册」**：进入登录流程。
8. **次按钮「游客继续，先逛逛」**：直接进入首页。
9. **游客能力说明**：明确游客数据仅保存在本机，不强迫登录。
10. **隐私说明**：可折叠查看本地保存、合并和上传限制说明。

## 页面结构

- 顶部：响应式品牌视觉区（漂浮元素 + 自绘「巴食」）。
- 中上：像素立体相框主插画 + 说明气泡。
- 中部：特性行 ×3。
- 底部：登录 / 游客入口 + 隐私说明。

## 响应式规则

- 页面内容最大宽度沿用移动端统一约束；窄屏不允许横向溢出。
- 漂浮元素使用 0–1 的相对锚点和宽度比例，不使用固定 left/top/width/height 屏幕像素组合。
- 品牌视觉区高度由可用宽度和宽高比推导，并设置合理最小/最大范围，避免平板上无限放大。
- 相框厚度、阴影偏移和内边距从容器宽度推导，并限制在小范围内，确保不同设备视觉重量一致。
- 系统开启「减少动态效果」时，漂浮元素停止动画但保留正确布局。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 品牌视觉、两个入口与三条能力说明完整展示 |
| 空状态 | 欢迎页无业务数据依赖，不出现空白占位 |
| 加载态 | 准备游客本地空间时禁用入口并显示加载状态 |
| 成功态 | 登录或游客入口按既有会话流程进入应用 |
| 错误态 | 本地空间准备失败时显示可重试提示 |
| 弱网 / 离线 | 登录可能不可用，但游客入口与本地说明仍可用 |
| 权限拒绝 | 欢迎页自身不主动申请权限，不阻塞游客进入 |
| 极限内容 | 320px 级窄屏与大字体下可纵向滚动，不横向溢出 |
| 游客态 | 明确本地保存与游客继续入口 |
| 登录态 | 已有会话由应用路由跳过欢迎页，不重复要求登录 |

## 非目标

- 本任务不修改登录、会话、游客数据或隐私策略。
- 本任务不重做下方特性行、按钮和隐私面板的业务行为。
- 本任务不新增网络字体或第三方绘图依赖。

## 走查要点

- 「巴食」使用 Fusion Pixel 像素字体清晰渲染，可辨识为品牌字。
- 五个小元素在 320px、430px 与平板宽度下保持相对构图，不贴边裁切、不压住标题。
- 相框能看出浅色框带和右下投影，不是单层绿色描边。
- 页面仍可滚动，登录、游客、重试按钮 key 与行为保持不变。
