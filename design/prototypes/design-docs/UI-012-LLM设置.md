# UI-012 LLM API 设置

- 所属模块：DESIGN-003 设置
- 关联：US-006（自定义 LLM）
- 目标：让用户配置自己的 LLM API，Key 不明文回显，测试失败稳定报错。

## 功能清单

1. **Base URL 输入**：自定义 API 地址。
2. **API Key 输入**：**不明文回显**（以掩码 / 圆点显示），可清空。
3. **模型选择 / 备注**。
4. **测试连接按钮**：
   - 点击后按钮内像素 loader 跳跃（约 1.5s）。
   - 失败：显示安全错误条（如「测试失败：无法访问该 Base URL」），**不暴露服务端细节**。
5. **清空 Key**：确认后清空。
6. **能力说明**：说明请求直连用户配置的服务商，不经过平台中转。

## 页面结构

- 顶部：标题「LLM API 设置」+ 返回。
- 内容区：Base URL / Key / 模型字段 + 测试连接按钮 + 错误条（按需）。
- 底部：保存（或随输入即时生效）。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 字段可填 |
| 测试失败 | 安全错误条，不暴露细节 |
| Key 已填 | 掩码显示，不回显明文 |
| 清空 | 二次确认 |

## 走查要点

- Key 绝不明文回显，这是合规底线。
- 测试连接的失败文案必须安全（不泄露堆栈 / 内部域名）。
- 测试连接要接像素 loader 动效。
