# UI-016b 推荐分组样式方案对比（内部评审稿）

- 所属模块：DESIGN-005 冰箱与推荐
- 用途：为 UI-016 的「结果分组头」挑选设计方案。同一组示例卡片（已具备 / 缺 1 样 / 缺 2 样 / 优先清库存）横向对比四个方向，供设计师 / 产品挑选后落地到 UI-016。

## 四个方案

**方案 A · 像素旗标带**
色带 + 计数徽标 + 向右延伸像素虚线。色带承载语义色（绿=已具备 / 琥珀=缺 1 样 / 蓝=缺 2 样 / 红=清库存），扫读最快，游戏感强，与按钮缺角语言同源。

**方案 B · 大号像素编号**
超大等宽编号「01 / 02」+ 中文组名 + 英文眉题（READY TO COOK / MISSING ONE）+ 下方虚线规则线。最克制高级，编辑部杂志感，最贴合「偏现代」定位。

**方案 C · 货架吊牌**
带打孔圆孔的吊牌 + 一截挂绳 + 卡片沿左侧牵引虚线「挂」下来。与冰箱的层架 / 抽屉是同一套「生活器物」隐喻，世界观最统一。

**方案 D · 色条面板**
整个分组是浅色调容器，左侧 4px 色条 + 组名 + 计数。分组边界最强最整齐，但色块面积最大，组多时页面偏花。

## 推荐

- 想和冰箱页统一 → 选 C（吊牌与层架 / 抽屉是一家子）。
- 想高级克制 → 选 B（编号 + 英文眉题最编辑部）。
- 想扫读效率 → 选 A。
- D 不推荐（色块多，削弱「长期使用不疲劳」目标）。

可混搭，如 B 的编号 + C 的牵引线。选定后应用到 UI-016 正式分组（四分组各配语义色：已具备绿 / 缺 1 样琥珀 / 缺 2 样蓝 / 清库存红）。
