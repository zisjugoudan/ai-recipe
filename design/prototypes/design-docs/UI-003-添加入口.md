# UI-003 添加入口

- 所属模块：DESIGN-001 链接导入全流程
- 关联：US-004（创建菜谱的多种方式）、US-005（剪贴板检测）
- 目标：集中承载所有创建菜谱的方式，作为 FAB 的落地页。

## 功能清单

1. **五种创建入口**（卡片/列表项，每项带像素图标 + 标题 + 说明）：
   - 粘贴链接：小红书 / 抖音公开链接。
   - 粘贴文本：用户手动复制的正文。
   - 导入图片：菜谱截图 / 食材图（取决于 OCR Provider）。
   - 导入视频：本地视频 / 平台视频降级（取决于 ASR / OCR / LLM 能力）。
   - 手动创建：直接编辑菜谱结构（不依赖 AI）。
2. **来源能力提示**：对每种入口标注所需能力（如图片→本地 OCR / 视频→ASR），让用户在开始前知道会用到什么。
3. **剪贴板检测提示**：若剪贴板有疑似链接，页面可提示「检测到链接，是否导入？」——**只提示，不自动读取后发请求**，必须用户确认。
4. **能力不可用引导**：游客未配 LLM、本地 OCR 未安装、额度不足等场景，给出引导（去设置 / 改手动创建），不阻断其他入口。

## 页面结构

- 顶部：标题「添加菜谱」+ 返回。
- 内容区：5 个入口项（图标 + 标题 + 说明 + 右侧箭头）。
- 底部：无主按钮（各入口自行跳转）；进入此页时隐藏 FAB。

## 状态覆盖

| 状态 | 处理 |
|---|---|
| 默认 | 5 入口全展示 |
| 剪贴板含链接 | 顶部提示「检测到链接，是否导入？」 |
| 能力缺失 | 对应入口下方灰色提示 + 引导 |
| 游客 | 链接 / 文本 / 手动创建可用；OCR / 云能力按设置 |

## 走查要点

- 5 入口为并列列表，不要在底部导航再占一个 Tab（添加由 FAB 触发）。
- 剪贴板提示只允许「建议」，不允许静默发起网络请求。
- 每个入口的「所需能力」用小标签呈现，避免用户点进去才发现做不了。
