# 测试与质量目录

本目录保存自动测试、人工验收、真实样本结果和回归证据。

## 子目录

- `acceptance/`：按用户故事记录人工验收。
- `integration/`：API、Schema、Provider 和同步契约测试。
- `ai-quality/`：OCR、ASR、LLM 的真实质量数据。
- `fixtures/`：经授权或可公开使用的固定测试样本及说明。

## 固定测试层级

1. 领域模型和校验规则单元测试。
2. 本地数据库、迁移和同步逻辑测试。
3. Provider 契约测试。
4. 导入流水线集成测试。
5. iOS/Android 关键流程端到端测试。
6. 用户故事人工验收。
7. AI 真实样本质量评估。

## 完成标准

- 代码能运行不等于功能完成。
- 每个 `DONE` 任务必须有对应验证记录。
- AI 功能必须同时检查字段准确性和需要人工修改的数量。
- 平台 Adapter 必须能独立回归。
- 测试失败不能通过修改验收标准来掩盖，除非产品需求确实变更且已先更新事实源。
