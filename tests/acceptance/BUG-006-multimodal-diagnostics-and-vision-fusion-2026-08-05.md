## 1. 验收边界

1. 多模态设置页不再把所有失败笼统显示为“链接超时”，能够定位失败阶段、耗时、状态码和下一步。
2. 自动识图按 OCR 与多模态独立执行、部分成功和证据融合工作，不因其中一路失败丢弃另一路结果。

本文件不要求回传 API Key、Authorization、完整服务地址、完整图片、完整 Prompt 或完整模型响应。截图和日志必须脱敏。

## 3. 基础连接与错误分类矩阵

每个场景记录：平台、Provider/模型别名、操作、诊断阶段、中文提示、HTTP 状态、耗时、下一步、截图/脱敏日志和实际结果。

| 场景 | 注入方式 | 预期分类 |
|---|---|---|
| 无效 URL / 非 HTTP(S) | 输入非法地址 | `config_validation` 失败，不发网络请求 |
| DNS、TCP、TLS 或连接拒绝 | 不可达主机/端口/证书 | `endpoint_resolution` 或 `connection_open` 失败 |
| 401 / 403 | 错 Key 或无权限 | `authentication` 失败，提示检查 Key/权限 |
| 404 / 405 | 错路径或方法 | 地址/协议错误，不显示普通超时 |
| 400 / 422 | 图片字段、模型参数或 data URL 不兼容 | 图片协议/请求 Schema 错误 |
| 413 | 超大图片 | 请求体过大，提示压缩或减少图片 |
| 415 | MIME 不支持 | 图片类型不支持 |
| 429 | 限流/配额不足 | 限流或配额错误，显示可重试建议 |
| 5xx | Provider 内部失败 | Provider/网关错误，不显示客户端超时 |
| HTTP 408 / 504 | 服务明确返回 | Provider/网关超时，保留状态码并区别客户端计时器 |
| 已连接但无首字节 | 服务接收后不返回头/正文 | 无首字节超时，阶段为 `first_byte` |
| 已有正文但连接不结束 | 返回部分 JSON 后悬挂 | 正文空闲或 `body_complete` 超时 |
| SSE 不发送终止标记 | 流持续打开 | 流未正常终止，不误报连接失败 |
| HTTP 200 + 错误 Schema | 返回无法解析的 JSON | `response_parse` 失败 |
| 客户端取消 | 请求中点击取消/离开页面 | 显示已取消，不显示超时，不自动重试 |

通过标准：所有场景的中文分类、阶段、状态码、耗时和下一步与实际注入一致；日志无敏感信息。

## 4. 三类测试入口

### 4.1 检查基础连接

1. 使用可用服务执行。
2. 确认显示配置、连接、鉴权和模型阶段。
3. 对视觉专用、明确拒绝纯文本的模型执行一次。

预期：可用服务通过；视觉专用模型若已返回合法的“需要图片/不支持文本”响应，显示“服务与鉴权已通过，文本能力未确认”，不显示网络超时。

### 4.2 检查图片能力

1. 执行内置标准图测试。
2. 分别模拟：文字和红块都正确、只识别文字、只识别红块、两者都错误、响应不是 JSON。

预期：只有 `text == "AI RECIPE 314"` 且 `redSquare == true` 同时满足才通过；其他情况停在 `image_assertion` 或 `response_parse`，并说明具体断言。

### 4.3 用我的图片测试

1. 主动选择真实图片。
2. 确认识别期间有加载和取消状态。
3. 完成后查看视觉观察/识别文本、Provider、模型、耗时和质量提示。

预期：不以一次成功代替真实质量判断；取消、权限拒绝、文件无效和超大图片均有稳定中文结果。

## 5. OCR / 多模态融合矩阵

| 场景 | 预期 |
|---|---|
| OCR 成功，多模态失败 | 保留 OCR 原文并继续生成；标记视觉观察缺失 |
| 多模态成功，OCR 失败 | 保留视觉观察并继续生成；标记文字提取缺失 |
| 两路成功且一致 | 合并来源，不重复堆叠相同信息 |
| 两路成功但冲突 | 确认页显示候选值和来源，不静默覆盖 |
| 两路失败但有正文/字幕/ASR | 使用已有证据继续生成 |
| 两路失败且无其他证据 | 不生成空草稿；提供重选图片、粘贴正文、手动创建 |
| 用户禁止上传 | 无云 OCR/多模态网络请求；本地 OCR 可继续 |
| 自动模式 | 两路独立执行、分别结算；受权限、网络、预算约束 |
| 仅 OCR | 不调用多模态；保留 OCR 坐标、顺序、语言、置信度 |
| 仅多模态 | 不调用 OCR；输出是视觉观察而不是伪造 OCR 原文 |
| 取消任务 | 停止未开始/可取消请求，已成功证据不被迟到结果覆盖 |
| 超过图片/并发/费用上限 | 停止后续调用，保留已成功证据并提示继续或降级 |

## 6. 页面状态覆盖

- 默认态：三类入口、当前 Provider/模型和隐私状态清楚。
- 空状态：未填地址、模型或 Key 时给出字段级提示。
- 加载态：显示当前阶段、已耗时和取消入口，不无限转圈。
- 成功态：显示通过阶段、断言、耗时和 Provider/模型别名。
- 错误态：显示具体分类、阶段和下一步，不直接透出完整服务正文。
- 弱网/离线态：离线不发云请求；弱网能区分无首字节与正文卡住。
- 权限拒绝态：相册/文件权限被拒后可返回设置或改用其他入口。
- 极限内容态：超大图、多图、长 OCR 文本、长视觉响应受上限控制。
- 完成态：结果可返回设置或继续真实图片测试，无残留 loading。
- 游客态：可用本地 OCR/自有 Provider，不显示平台托管服务已可用的假状态。
- 登录态：只有具备真实服务能力时才显示平台托管选项。
