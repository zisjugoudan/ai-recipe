# DESIGN-008 Image 2 严格二维像素美术提示词 v1.3 验收

> 日期：2026-08-10  
> 状态：等待项目负责人生成样张并回传，任务保持 `VERIFY`  
> 本轮边界：只验收 Prompt 与生成结果；Codex 不调用 Image 2、不生成图片、不接入 Flutter

## 1. 验收目标

确认「巴食」Image 2 提示词能够稳定产出与现有 UI 统一的严格二维像素资产，并验证：

1. 只有 4 项品牌资产使用官方水豚主厨 IP。
2. 状态、功能入口、冰箱/库存/推荐、分类和导航全部不使用任何角色或 IP。
3. 所有资产均无 3D、透视、厚度、渐变、软阴影、材质和柔滑抗锯齿。
4. 导航与分类的 `default` / `active` 状态在小尺寸下可辨且轮廓稳定。
5. 状态插图能在不依赖角色表演的前提下，仅靠物体和符号表达页面状态。

## 2. 范围

  - 冰箱 / 库存 / 推荐 10 项：禁止 IP。

## 4. IP 使用边界

### 4.1 允许 IP 的品牌 4 项

`design/assets/IP.png` 只允许决定以下品牌资产的官方身份：

| 文件 | 用途 |
|---|---|
| `brand-app-icon-capybara-chef-v1.png` | App 图标 |
| `brand-mark-capybara-chef-v1.png` | 品牌核心符号 |
| `welcome-hero-capybara-kitchen-v1.png` | 欢迎页 Hero |
| `recipe-cover-generic-capybara-cooking-v1.png` | 通用菜谱占位封面 |

品牌资产应保留金棕色水豚、圆胖比例、短肢、圆短耳、白色厨师帽、白色双排扣厨师服、黑色墨镜和粉红腮红；但不得继承平滑抗锯齿、渐变、柔光、体积光、厚涂、塑料、黏土或类 3D 画法。

品牌资产优先级：

```text
巴食 UI 风格与严格像素约束 > 官方 IP 身份 > 品牌构图细节
```

### 4.2 禁止 IP 的非品牌资产

以下资产不得上传或参考 `IP.png`、`封面图.png`：

| 分组 | 数量 |
|---|---:|
| 状态插图 | 12 |
| 功能入口 | 10 |
| 冰箱 / 库存 / 推荐 | 10 |
| 分类 default | 12 |
| 分类 active | 12 |
| 底部导航 default / active | 4 组 / 8 枚 |

非品牌资产必须同时满足：

- 不出现水豚、人物、厨师、厨师帽、墨镜、脸、眼睛、嘴、手、脚、四肢。
- 不出现拟人姿态、拟人表情、吉祥物、角色轮廓或任何 IP 特征。
- 只使用最简洁的功能物体、食材和符号表达语义。

非品牌资产优先级：

```text
巴食 UI 风格与严格像素约束 > 单项功能语义
```

## 5. 全局一票否决项

任一图片出现以下任一项，直接判定该图片不通过：

- 3D、等距视角、3/4 透视、可见侧面、顶面或厚度。
- 黏土、塑料、贴纸、emoji、游戏道具或拟真材质。
- 渐变、柔光、环境光、体积光、AO、软阴影、倒角、挤出。
- 平滑抗锯齿、亚像素曲线、柔和圆角矢量感、模糊边缘。
- 文字、汉字、字母、数字、水印、签名、第三方 Logo、设备框或页面 UI。
- 非品牌资产出现任何角色、人物、动物角色、厨师、五官、手脚、拟人表情、吉祥物或 IP 特征。
- active 与 default 的外轮廓、比例、位置、基线、像素矩阵或投影不一致。

## 10. 判定规则

### 10.1 通过

- 导航 8 枚双状态 glyph 全部通过。
- 早餐 default / active 叠放无位移且 40px 可辨。
- 冰箱空状态不使用角色并在 3 秒内表达正确语义。
- 品牌 4 项之外的所有样张均无角色、无 IP 特征。
- 未触发任何全局一票否决项。
- 代表样张与当前「巴食」UI 色板、像素密度、缺角、描边和硬投影一致。
- 品牌 4 项中的 IP 可被判断为同一位官方水豚主厨。
- 项目负责人明确反馈通过。

### 10.2 不通过

任一资产触发一票否决项，或出现以下问题，即判该项不通过：

- 非品牌资产出现任何角色或 IP 特征。
- 品牌资产 IP 身份错误。
- 状态语义错误。
- 小尺寸不可辨。
- default / active 轮廓漂移。
- 透明边污染。

记录失败原因并收紧对应 Prompt，不得带着失败方向批量生成。
