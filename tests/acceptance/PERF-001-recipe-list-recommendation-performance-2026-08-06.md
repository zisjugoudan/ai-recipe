# PERF-001 菜谱列表与推荐性能优化验收方法

> 对应解决方案：`解决方案.md`（列表摘要查询 / 消除 N+1 / 分页 / 虚拟化 /
> 推荐轻量数据 / Isolate / 限量展示 / 防抖与最新请求优先）
>
> 创建：2026-08-06　状态：VERIFY（等待项目负责人执行）

## 一、任务目标

按《解决方案.md》把“约 5001 次串行 SQL + 全量构建卡片 + 推荐 UI 主线程计算”
这条昂贵链路替换为：

1. 菜谱库列表改用 `RecipeSummary` 摘要分页查询（单条 SQL，含食材数量聚合），
   不再逐条加载完整聚合（消除 N+1）。
2. 列表使用 keyset pagination（updated/created/title 三种排序），
   滚动到底自动加载下一页，不再一次性读取全部 1000 条。
3. 卡片渲染改为 `SliverGrid` 虚拟化，只构建屏幕附近的卡片。
4. 首页改用摘要 + 分类计数，不再全量读取完整聚合。
5. 推荐读取专用轻量数据（主记录 + 食材批量查询，约 2 次 SQL，
   不含步骤/图片/分类）。
6. 推荐匹配计算放入后台 Isolate，界面不卡死；Web/测试回退直算。
7. 推荐每组首批只展示 Top 10，剩余通过“查看更多”增量展示。
8. 推荐交互 250ms 防抖 + 最新请求优先（旧请求结果不覆盖新选择）。
9. 标准化器增加结果缓存，别名/规格词典改 Map 查找，库存候选改家族索引。
10. 数据库 v10 迁移新增复合索引。

## 二、测试平台与前置条件

- Android 模拟器或真机（Debug 构建）。
- 使用“我的 → 开发者工具 → 生成 1000 条测试菜谱”准备 1000 条 published 菜谱
  （或导入足够多的正式菜谱）。
- 冰箱“库存”页有若干常用食材批次（如 番茄/鸡蛋/精瘦肉/青椒/盐/油）。

## 三、测试方法（按步骤执行并记录结果）

### 1. 菜谱库首屏速度

1. 清空最近任务/返回首页，进入“菜谱库”Tab。
2. 预期：首屏在 1~2 秒内出现（原先可能几分钟），页头显示“共 1000 道菜谱”。
3. 记录：进入菜谱库到卡片出现的时间；是否出现长时间加载动画（不应再有）。

### 2. 列表滚动加载（分页 + 虚拟化）

1. 在菜谱库向下快速滚动到底部。
2. 预期：滚动流畅，接近底部时自动加载下一页（页脚出现“加载更多”/加载指示），
   滚动时只构建屏幕附近卡片，不一次性创建 1000 张。
3. 记录：滚动是否卡顿；到底部后“已加载全部 · 共 1000 道”是否出现；
   期间 App 是否可返回/可操作。

### 3. 搜索 / 排序 / 分类筛选

1. 在搜索框输入“性能测试菜谱 500”，等待 300ms 防抖。
2. 预期：只显示 1 条结果，总数变为 1。
3. 切换排序：最近更新 / 创建时间 / 名称排序。
4. 预期：每次切换后重新加载第一页，排序正确，无整页加载动画闪烁。
5. 点“收藏”筛选：偶数条为收藏，预期约 500 条。
6. 点某个分类 chip：只显示该分类菜谱。
7. 记录：各操作响应时间与是否出现加载动画/错误。

### 4. 首页速度

1. 强制停止 App 后重新打开，进入首页。
2. 预期：首页快速出现（原先首页也会全量读取完整聚合），分类卡片计数正确、
   “最近浏览”“我的收藏”正常显示。
3. 记录：首页加载时间与计数是否正确。

### 5. 推荐数据准备与计算不卡界面

1. 进入“冰箱 → 推荐”，点选“番茄”和“鸡蛋”。
2. 点击“用已选食材推荐（2）”。
3. 预期：①点击后界面立即出现加载指示，页面仍可滚动/可返回（不再“死机”）；
   ②等待后出现“现在就能做”分组，包含“番茄炒蛋”类菜谱；
   ③卡片显示“已选命中 · 番茄”等标签。
4. 记录：从点击到结果出现的时间；计算期间页面是否可操作。

### 6. 快速连续勾选（防抖 + 最新请求优先）

1. 在推荐页快速连续点选/取消多个食材 chip（1 秒内 5 次以上）。
2. 预期：不出现多次“正在计算”叠加，只在停顿后计算一次；
   最终结果与最后一次选择一致（旧选择的结果不会被新选择覆盖）。
3. 记录：是否出现结果与选择不一致的情况。

### 7. 推荐结果限量展示（Top 10 + 查看更多）

1. 点选“全部”（或用临期优先/全选），使某分组结果超过 10 条。
2. 预期：每组只显示前 10 条卡片，组标题显示总数；
   点击“查看更多（N）”后显示剩余卡片。
3. 记录：分组标题数量、初始卡片数、查看更多是否生效。

### 8. 收藏乐观更新

1. 在菜谱库卡片点收藏图标。
2. 预期：图标立即切换，无整页刷新/加载动画；返回首页后收藏区刷新。
