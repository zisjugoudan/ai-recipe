## 2. 操作步骤与预期结果

### 2.1 多图独立 → 多份草稿

1. 粘贴"多图独立"链接创建导入任务。
2. 预期：进度页显示"正在识别图片内容"→"正在生成结构化菜谱"；完成后进入确认页。
3. 若 LLM 分组判断为 independent：确认页按图片数逐份展示草稿（第一份标题/正文与其余份），每份草稿对应一张图片的完整菜谱；保存第一份后返回任务（其余草稿保留），再次进入可继续确认下一份。
4. 回传：草稿份数、每份菜名与主要食材/步骤是否与对应图片一致、分组判断是否准确、需人工修改处。

### 2.1.1 多草稿弹窗：像素风、单项删除与多选删除

1. 多图独立任务完成进入多草稿弹窗后核对：弹窗为像素风容器（墨色切角描边，与粘贴文本导入弹窗一致），标题"N 道菜谱"，右上角有关闭按钮（唯一退出入口），底部有"全部确认"（不再有"稍后处理"）；点击弹窗空白处不关闭，只有点关闭按钮才退出。
2. 点击某一行：进入该草稿编辑确认页；保存后返回首页（该草稿入库）；仅按返回（不保存）回到多草稿弹窗，弹窗保留，可继续点击其他草稿或删除。
3. 单项删除：点击某项右侧删除图标，弹出二次确认（"删除这份菜谱草稿？"），确认后该项从弹窗消失；去回收站可找到该草稿并可恢复。
4. 多选删除：勾选多项（左侧勾选框，选中项绿色高亮）或**长按某条目进入选择模式**（长按选中该项，之后点按其他条目切换选中，副标题显示"已选择 N 项"），底部出现"删除所选 (N)"，确认后批量删除；取消全部选中自动退出选择模式。
5. 删除全部草稿：最后一份删除后任务进入"解析已取消"，返回进度页。
6. 误添加防护：①点"全部确认"应弹出二次确认（"确认全部添加这 N 道菜谱？"），取消则不入库；②点某行进入确认页后按返回（不点"保存菜谱"），应回到多草稿弹窗继续处理，菜谱库不应出现新菜谱。
7. 回传：弹窗风格是否符合像素风、单项/批量删除是否生效、回收站恢复是否可用、删光后任务状态、返回不添加与"全部确认"二次确认是否生效。

### 2.2 多图合成 → 单份草稿

1. 粘贴"多图合成"链接创建导入任务。
2. 预期：只产出 1 份草稿，内容整合了所有图片的步骤与配料，步骤顺序与图片顺序一致。
3. 回传：草稿完整性、步骤顺序、是否遗漏某张图内容。

### 2.3 单图 → 单份草稿（回归）

1. 粘贴单图菜谱链接。
2. 预期：产出 1 份草稿，行为与 IMAGE-001 一致；确认页证据面板显示"OCR 文字"来源标签。

### 2.4 手动选图/拍照导入：OCR 未安装时回退多模态

1. 确认本地 OCR 模型未安装（识图引擎页显示未安装）。
2. 快速导入→拍照选图，选择一张含菜谱文字图片。
3. 预期：不再提示"先安装 OCR"，而是使用多模态 LLM 转录并生成草稿（识图引擎全局设置为"自动"时）。
4. 回传：是否成功回退、转录文本质量、需人工修改数。

### 2.5 成本与取消（边界）

1. 多图任务识别期间点击取消。
2. 预期：立即停止后续图片识别/分组/生成，任务进入"已取消"，不显示超时；不产生新的草稿或残留任务状态。
3. 极端情况：9 张图（或链接更多图）时只处理前 9 张并标记"部分内容"；失败/断网给出稳定中文错误。

### 2.6 重启恢复

1. 多草稿任务处于 needsReview 时强停重启应用，进入"未完成导入"列表打开该任务。
2. 预期：仍可逐份查看/确认草稿（草稿 ID 已持久化）。

## 4. 已知限制

- 分组判断依赖纯文本 LLM 输出 JSON；判断失败时**回退为全部合并**（单草稿），不丢弃内容。
- 手动选图路径在 OCR"运行期识别失败"时暂不自动换多模态（仅"未安装/不可用"时回退）；运行期失败仍按既有 OCR 错误提示，后续迭代处理。
- 多图独立时每份草稿只带该图对应封面；作者正文仅并入第一份草稿。
