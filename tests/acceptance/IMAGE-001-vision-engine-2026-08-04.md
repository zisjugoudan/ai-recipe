# IMAGE-001：识图引擎——图片识别方式可选（OCR / 多模态 LLM）+ 独立多模态配置

> 日期：2026-08-04
> 状态：`VERIFY`（Android 已实现，等待项目负责人复测；iOS 未验证）
> 平台：Android
> 关联：`ADR-0027`、`OCR-001`、`OCR-002`、`OCR-003`、`IMPORT-007`

## 1. 用户价值

导入小红书/抖音图文笔记或本地图片时，用户可以选择用**本地 OCR**（只识别图片中的文字）还是**多模态 LLM**（理解图片整体语义：食材摆盘、步骤图、手写便签）来提取图片内容。多模态 LLM 拥有独立配置，与菜谱生成 LLM 完全分离，互不影响。

## 2. 已实现

- **识别方式设置**（识图引擎页顶部"图片识别方式"）：
  - `自动`：多模态 LLM 可用优先，否则回退本地 OCR，再否则不识别图片（默认）；
  - `仅 OCR`：只用本地 OCR；
  - `多模态 LLM`：只用图片识别 LLM。
  - 选择后点"保存"持久化（`LocalAppSettings.imageRecognitionMode`，SQLite v8 迁移）。
- **独立多模态配置**（识图引擎页"多模态 LLM 图片识别"区）：
  - Provider 类型（OpenAI-compatible / Gemini）、API 地址、模型、API Key（安全存储）、超时；
  - 保存/测试连接/清除 Key，与菜谱生成 LLM（本地 LLM API 页）完全独立。
- **多模态 Provider**（`MultimodalLlmProvider`）：
  - OpenAI-compatible：`image_url` content 块，图片转 data URL；
  - Gemini：`inline_data`（base64）；纯文本请求复用现有 generate 用于连接测试；
  - 图片字节上限 8 MB，魔数校验 JPG/PNG/WebP。
- **识别链路**（`MultimodalImageEnrichingImportContentProcessor`）：
  - 与 OCR 版平行：配图经安全暂存下载/校验 → 读字节 → 多模态识别 → 提取内容并入 `ImportContent` 证据 → LLM 生成草稿；
  - 固定中文提示词要求提取菜名/食材用量/步骤，无关图片输出"（图片与菜谱无关）"；
  - 错误统一映射为稳定中文文案（未配置、Key 无效、限流、超时、网络等）。
- **执行计划**（`ImportImageRecognitionRoute { disabled, ocr, multimodal }`）：
  - `_resolveDefaultPlan` 按设置 + 能力快照自动解析（链接导入与本地图片导入共用）；
  - `AppCapability.multimodalLlm` 能力：已保存配置 + Key → ready，否则 notConfigured。
- **入口改名**："我的 → OCR 设置"改为"识图引擎"，设置页标题同步。

## 3. 已知限制

- 多模态识别质量取决于所选模型是否真正支持图片输入；测试连接只验证连通性，不验证视觉能力，用户需自行选择视觉模型。
- 图片经安全暂存后 base64 发送给第三方多模态服务：发送前会先校验大小/类型；平台图片地址在暂存下载后不再暴露给服务方（只发送图片字节）。
- 远程图片字节仍经 OCR-002 安全暂存层校验（HTTPS、尺寸/大小限制）。
- iOS 未验证。

## 4. Android 人工复测步骤

### 4.1 前置条件

1. 安装包含 `IMAGE-001` 的 Android 构建。
2. 准备一个多模态（视觉）模型的 API 地址/Key/模型名（如支持 vision 的 OpenAI-compatible 或 Gemini 服务）。
3. 本地 OCR 模型已安装（用于对比"仅 OCR"）。

### 4.2 操作步骤

1. 进入"我的 → 识图引擎"，顶部"图片识别方式"选择"多模态 LLM"并保存。
2. 在"多模态 LLM 图片识别"区填写 API 地址、模型、Key，点"测试连接"确认成功（若网络不可达应在约 20 秒内返回失败，不会无限转圈），点"保存配置"（保存应很快完成，不长时间转圈）。再点"测试识图（选一张图片）"，选一张含菜谱信息的图片：确认结果卡片显示多模态模型输出的识别文本、耗时（ms）与模型名。
3. 回到首页"快速导入 → 拍照选图"，选择一张含菜谱信息的图片（可含手写/摆盘等纯 OCR 难处理的内容）：
   - 确认进入"正在识别图片内容"阶段，草稿包含多模态模型提取的菜名/食材/步骤；
   - 打开"原文证据"，确认存在多模态识别文本片段。
4. 把识别方式改回"仅 OCR"并保存，用同一张图再导入一次：确认走本地 OCR（只提取图中文字）。
5. 把识别方式改为"自动"并保存：删除多模态配置（或清空 Key）后导入，确认回退到本地 OCR；同时删除 OCR 模型后导入，确认回退纯文本/正文路径。
6. 未配置多模态时选择"多模态 LLM"导入图片：确认提示"请先在识图引擎中配置图片识别 LLM"之类中文引导。
7. 多模态识别超时/断网：确认稳定中文错误（超时/网络不可用），不出现底层英文。

### 4.3 预期结果

- 识别方式设置保存后立即生效，链接/图片导入按所选方式识别图片并把内容并入草稿；
- 多模态配置可独立保存/测试/清除，不影响菜谱生成 LLM；
- 能力不可用时按设置回退（自动）或给出中文引导（固定方式）。
