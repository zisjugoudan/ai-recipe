# IMPORT-008 WebView 抓取生命周期与竞态加固验收方法

> 对应：《解决方案.md》（第一阶段：生命周期与竞态）；ADR-0032；并入 IMPORT-008。
>
> 创建：2026-08-06　状态：VERIFY（等待项目负责人 Android 真机执行）

## 一、任务目标

修复 WebView 抓取的不稳定，重点验证：

1. **请求隔离**：旧请求的迟到回调绝不污染新请求（`ctx === activeRequest` +
   `navigationGeneration`/`imageGeneration` 双代次）。
2. **新请求正确终止旧请求**：新请求启动时旧请求标记为 superseded 并彻底停止，
   不显示"网页超时"。
3. **原生取消**：用户取消后原生立即停止导航/JS/图片下载写盘，取消记为
   `cancelled`（而非 timeout），且不产生多余网络请求。
4. **真实总超时**：Dart 传入的 timeoutMs 是该请求绝对上限，各阶段不能累计超过。
5. **renderer gone 重建**：渲染进程崩溃后销毁重建 WebView，下一次请求能恢复。
6. **请求专属图片目录**：不同请求的图片写入各自目录，互不污染。

## 二、前置条件

- Android 模拟器或真机（Debug 构建）。
- 已配置"识图引擎 → 多模态 LLM 图片识别"与菜谱生成 LLM（用于把抓取结果走完
  导入流水线）。
- 稳定的小红书图文链接、抖音视频链接、普通菜谱网页链接各一个。
- 外部终端可查看 Logcat（`adb logcat -s WebViewFetch`）。

## 三、测试方法（逐项执行并回传结果）

### 1. 请求隔离（旧请求不污染新请求）

1. 连续两次快速发起导入（在 A 尚未结束时启动 B，例如 A 用慢网页、B 用快网页）。
2. 观察 Logcat。
3. 预期：A 与 B 的 `req=1` / `req=2` 日志互不串扰；B 启动时 A 被标记
   `superseded`；A 的迟到回调（若有）被丢弃，不把 A 的结果/图片写进 B。
4. 记录：是否出现 cross-request 污染；A 的结束分类。

### 2. superseded 语义

1. 重复上述并发请求。
2. 预期：被新请求替代的旧请求以 `superseded` 结束，Dart 侧映射为
   `cancelled`（不显示"网页加载超时"）。
3. 记录：旧请求最终 error code；用户看到的提示文案。

### 3. 取消不被记为超时

1. 抓取进行中（导航或图片阶段）点击"取消解析/取消"。
2. 预期：任务记为已取消（`cancelled`），快速结束；原生停止后续下载/JS；
   Logcat 出现 `cancelled` 而非 `timeout`。
3. 记录：取消后任务状态；是否仍有后续请求；结束分类。

### 4. 总超时确为请求上限

1. 用一条最终会超时的慢链接（或弱网），设一个较短的内部 timeout（如 10s）。
2. 预期：请求在约 timeoutMs 内结束，各阶段累计不超过该绝对值；
   Logcat 出现 `REQUEST_TIMEOUT total=<ms>ms`。
3. 记录：从发起到结束的实测耗时；是否超过配置的 timeoutMs。

### 5. renderer gone 后重试可恢复

1. 触发或模拟渲染进程崩溃（`adb shell am crash` 目标进程，或强杀 WebView 进程）。
2. 立即重试同一链接。
3. 预期：首次以 `rendererGone` 结束；重试时 WebView 重建（Logcat 可见重新加载），
   能正常进入导航/提取；不再持续失败。
4. 记录：崩溃后的错误分类；重试是否成功。

### 6. 正文成功后图片失败不整单失败（回归）

1. 用图片全部 403／缓慢的链接导入。
2. 预期：正文正常返回生成草稿，仅配图数量偏少；不出现"网页加载超时"整体失败。
3. 记录：正文是否成功；保存成功图片数；用户提示。

### 7. 请求专属图片目录（回归）

1. 两次导入不同请求，期间触发一次取消。
2. 预期：取消/失败请求的图片目录被清理，不残留到新请求；成功请求的图片
   路径位于 `filesDir/webview-imports/<requestId>/images/`，Dart 能正常读取。
3. 记录：图片本地路径；是否发生目录串扰。

### 8. 常规回归

1. 单链接导入、普通网页导入、登录墙/验证码/已删除页面分类提示不回归。
2. 连续导入 10 次同一链接，确认稳定且无旧回调污染。
