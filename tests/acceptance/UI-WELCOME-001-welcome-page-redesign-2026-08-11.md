## 目标与范围

本轮只调整参考图红框内的欢迎页顶部视觉区：

1. 厨师帽、胡萝卜、番茄、辣椒、叶子按参考图环绕标题排布。
2. 五个小元素的位置、尺寸和浮动幅度按可用容器宽度计算，不绑定某一设备的固定屏幕坐标。
3. 「巴食」使用项目内置的 Fusion Pixel 像素字体（支持简体中文，OFL-1.1）以 `Text` 渲染，保留深绿色主体与右下立体阴影，不使用系统中文字形。
4. 主插画使用多层像素立体相框：右下投影、墨绿外轮廓、深绿框体、浅色框带、上/左高光、下/右压暗、内侧深绿压边。
5. 插画下方说明气泡的尾巴向上连接插画，右下红色爱心完整显示。
6. 特性列表、登录 / 游客入口、隐私说明和错误处理保持原行为。

## 前置条件

1. 项目负责人在 `code/apps/mobile` 下准备好 Flutter 依赖与可运行环境。
2. 使用能够调整窗口宽度的模拟器、桌面调试窗口或至少三台不同宽度设备。
3. 保留本地参考图，视觉检查时并排对照红框区域。

## 人工视觉与交互验收

### A. 三种宽度逐一检查

分别以以下视口打开欢迎页并截图：

| 视口 | 建议尺寸 | 重点 |
|---|---:|---|
| 窄屏 | 320 × 900 | 不横向溢出；小元素不裁切、不压住标题；页面可以纵向滚动 |
| 常规手机 | 430 × 900 | 与参考图红框的相对构图最接近 |
| 宽屏 / 小平板 | 600 × 1000 | 内容保持居中；顶部构图不会无限放大或散开 |

每个宽度检查：

1. 顶部中央为可辨识的「巴食」，有深绿色主体和右下硬边阴影；不能表现成系统中文字体或一张字标图片。
2. 「巴食」下方小字为「拾味 · AI 菜谱」。
3. 厨师帽在左上，胡萝卜在左下，番茄在标题左上侧，辣椒在右上，叶子在右下；五个元素均完整可见。
4. 改变窗口宽度时，小元素相对位置和尺寸平滑变化，不出现某个固定像素布局只在一台设备正确的情况。
5. 主插画四周能明确看出多层立体框，而不是单层绿色描边：
   - 右下方有投影；
   - 外侧有墨绿轮廓和深绿框体；
   - 中间有浅色框带；
   - 上、左边更亮，下、右边更暗；
   - 图片内侧还有深绿压边。
6. 气泡顶部尾巴向上指向插画；文字为「把小红书 / 抖音上的菜谱，收进你的口袋厨房」；右下红色爱心没有被裁掉。
7. 气泡、插画和标题之间的间距接近参考图，不互相遮挡。

### B. 状态覆盖

| 状态 | 操作 | 预期结果 |
|---|---|---|
| 默认态 | 正常打开欢迎页 | 顶部视觉、三条特性、两个入口和隐私面板完整显示 |
| 空状态 | 使用无菜谱、无分类的新安装数据 | 欢迎页不依赖业务数据，不出现空白占位或报错 |
| 加载态 | 触发游客本地空间准备中状态 | 登录与游客入口禁用，游客按钮显示加载提示 |
| 成功态 | 分别点击登录和游客继续 | 进入现有登录流程或应用主页，顶部视觉修改不改变会话行为 |
| 错误态 | 注入本地会话准备失败信息 | 显示红色错误提示，可点击「重试」 |
| 弱网 / 离线态 | 断网后打开欢迎页 | 本地插画和小元素仍显示；游客入口与隐私说明仍可用 |
| 权限拒绝态 | 拒绝系统权限后返回欢迎页 | 欢迎页自身不主动索取权限，也不阻塞游客进入 |
| 极限内容态 | 320px 宽度并开启较大系统字体 | 可纵向滚动；不横向溢出；标题、小元素和相框不被裁切 |
| 游客态 | 点击「游客继续，先逛逛」 | 保持既有游客进入行为和本地保存说明 |
| 登录态 | 已登录后重新启动应用 | 仍按现有路由跳过欢迎页，不重复要求登录 |

### C. 减少动态效果

1. 在系统辅助功能中开启「减少动态效果」。
2. 重新进入欢迎页并停留至少 5 秒。

**预期结果**：五个小元素保持静止，但位置、大小和清晰度与默认态一致；「巴食」为静态像素字体、无动画；页面无卡顿或异常。

### D. 「巴食」像素字体渲染

1. 打开欢迎页，观察顶部「巴食」品牌字。
2. 分别以 320、430、600px 宽度查看。

**预期结果**：
- 「巴食」使用 Fusion Pixel 像素字体清晰渲染，两字可辨识，笔画边缘呈像素颗粒感。
- 保留深绿色主体与右下立体阴影（硬阴影偏移），无动画、无闪烁。
- 各宽度下标题不溢出、不裁切，与漂浮元素不重叠。
