# IMPORT-009：导入体验补强（快速导入分流 / 批量导入 / 未完成导入列表 / 进度条与正文去重修复）

> 日期：2026-08-03
> 状态：`DOING`（代码与测试定义已完成，等待项目负责人构建 Android 复测）
> 平台：Android（iOS 未验证）
> 关联：IMPORT-008、IMPORT-007、BUG-003

## 1. 用户价值

- 修复解析时进度条填充为 0（只剩百分比文字）的显示问题。
- 修复 WebView 提取结果"正文与简介内容相同"的重复问题。
- 快速导入 4 个按钮各自进入对应的真实流程，不再全部指向"添加菜谱"页。
- 支持一次粘贴多个链接批量创建导入任务。
- 未完成导入改为列表管理：可查看全部、点击继续、单个取消/删除、一键清空已结束记录。

## 2. 已实现

1. **进度条修复**：`PixelProgressBar` 填充条 `FractionallySizedBox` 缺 `heightFactor`（子项无固有尺寸 → 高度 0），已加 `heightFactor: 1.0`。
2. **正文/简介去重**：WebView 提取结果中 description 与 bodyText 相同（小红书笔记 desc 即正文）时只保留正文片段，不再重复展示。
3. **快速导入分流**（首页）：
   - 粘贴链接 → 打开添加页（链接 tab）
   - 剪贴板 → 读取系统剪贴板文本并预填到链接输入框
   - 拍照选图 → 系统相册选图 → 创建本地图片导入任务（本地 OCR + 自有 LLM，占位链接 `https://local-image/capture`，平台归 web）→ 打开进度页自动运行
   - 手动创建 → 直接打开完整菜谱编辑器
4. **批量导入**：添加页链接输入框支持多行/多个链接，一次性创建多个任务；单个失败不中断其余；全部失败显示首个错误；成功 ≥2 个时自动打开"导入任务"列表统一管理。
5. **未完成导入列表页** `ImportTasksPage`：列出排队/解析中/待确认/失败/已取消任务；点击进入对应进度页；排队/解析中可单个取消；失败/已取消可单个删除（二次确认）；顶部"清空已结束（N）"一键删除全部失败/已取消（二次确认）；首页"有 N 个未完成的导入"入口改打开此列表。
6. **长按多选与批量删除（2026-08-06 新增）**：长按任意任务进入选择模式并选中该项；选择模式下点按切换选中（全部取消自动退出）；顶部显示"已选择 N 项"与"全选/取消全选"按钮（全选选中列表全部任务，取消全选退出选择模式）；底部浮出批量操作栏"删除所选 (N)"，二次确认后批量删除；所有状态的任务都可删除，但进行中（排队/解析中）与待确认任务删除时，确认弹窗会提示"其中 X 条正在进行或待确认：删除将中断解析并移除已生成的 AI 草稿"，确认后先取消任务、清理全部关联草稿（主草稿 + 附加草稿）再删除记录；选择模式下隐藏单个取消/删除按钮，选中项显示深绿描边与勾选标记，底部操作栏提示"进行中/待确认任务将一并终止"。
7. **Facade 扩展**：`deleteImportTask`（全部未完成状态可删：已结束直接删，进行中/待确认先取消并清理全部关联草稿再删）、`deleteImportTasks`（批量）、`createLocalImageImportTask`；`runImportWithLocalImage` 放宽允许 queued 状态（新图片任务）。
8. 测试定义已更新/新增（未运行）：批量导入创建多任务并打开列表、空链接不创建、ImportTasksPage 列表显示/取消/删除/清空、长按进入选择模式、点按切换选中与空选退出、全选/取消全选、批量删除已结束任务、批量删除含进行中任务并弹窗提示后果、取消按钮退出选择模式、HomePage 新参数编译。
9. **全项目弹窗风格统一（2026-08-06 新增）**：新建共享像素风弹窗组件 `pixel_dialogs.dart`（`PixelConfirmDialog`/`PixelInfoDialog` 与 `showPixelConfirm`/`showPixelInfo`），统一基准样式（透明 Dialog + PixelSurface lg 切角 + 墨色 1.5px 描边 + 硬投影 + 标题 15px/w900 + 正文 12px/ink2 + 右对齐像素按钮）；清除全部原生 `AlertDialog`（导入任务/进度、回收站、隐私、OCR 设置、草稿确认、菜谱详情/编辑、冰箱批量操作、烹饪退出/完成等 12 处），删除三个本地重复确认类（`_PixelConfirmDialog`/`_LibraryConfirmDialog`/`_DevConfirmDialog`）统一走共享组件，"未保存修改"弹窗对齐基准样式；多草稿选择/生成进度/分类输入/剪贴板输入等特殊弹窗本身已是像素容器，保留不变。

## 3. 已知限制

- 图片导入（拍照选图）依赖本地 OCR 与自有 LLM 可用（复用 IMPORT-007 能力）；OCR 未安装时按既有提示引导安装。
- 进行中（排队/解析中）与待确认任务删除时会先取消并清理全部关联草稿再删除记录，后台解析会中断，无法继续原任务。
- iOS 未验证。

## 4. Android 人工复测步骤

### 4.1 前置条件

1. 在项目根目录执行 `flutter run` 并选择真机（DBR W10）。
2. 确认自有 LLM 已配置；OCR 设置中本地 OCR 模型已安装（拍照选图用例）。

### 4.2 操作步骤

1. **进度条**：粘贴单个链接开始解析，确认进度条绿色填充随百分比增长（不再是空条只显示数字）。
2. **正文去重**：导入一个小红书图文链接，草稿确认页应显示标题与正文一次（正文即笔记内容），不再出现"简介与正文相同"的两段重复文本。
3. **快速导入分流**：
   - 粘贴链接 → 应打开"添加菜谱"链接 tab；
   - 剪贴板 → 应先复制一个小红书链接到系统剪贴板，点"剪贴板"应打开添加页且链接已预填；
   - 手动创建 → 应直接打开菜谱编辑器（而非添加页）；
   - 拍照选图 → 应打开系统相册，选图后进入导入进度页并自动执行图片 OCR 导入。
4. **批量导入**：在添加页链接框粘贴 2 个链接（换行分隔），点开始解析 → 创建 2 个任务并自动进入"导入任务"列表。
5. **未完成导入列表**：首页"有 N 个未完成的导入"点入列表；对排队/解析中任务点"取消"；对失败/已取消任务点"删除"并确认；有失败/已取消记录时点"清空已结束"并确认，列表变为空状态。
6. **长按多选与批量删除**：列表内长按任意任务 → 进入选择模式并选中该项；再点按其他任务切换选中；点"全选"应选中全部（按钮变"取消全选"）；点"取消全选"或"取消"应退出选择模式回到普通列表；选中若干任务后点底部"删除所选 (N)"并确认，记录被删除；**混合选中进行中（排队/解析中或待确认）任务与已结束任务后点"删除所选"**，确认弹窗应提示"其中 X 条正在进行或待确认：删除将中断解析并移除已生成的 AI 草稿"，确认后应全部删除；删除进行中任务后，其草稿（若有）不应残留在"草稿箱/菜谱库"，且不出现孤儿记录。
7. 回归：单链接导入、失败任务降级（粘贴正文/上传截图）、保存草稿后首页刷新正常。
8. **弹窗风格统一**：依次触发以下确认弹窗——批量删除导入任务（含进行中任务）、单个删除失败/已取消任务、清空已结束、菜谱库批量删除所选、回收站永久删除/清空、隐私清空历史、OCR 删除模型、菜谱详情删除、菜谱编辑页返回（未保存修改）、冰箱批量操作、烹饪模式退出/完成——所有弹窗应为同一像素风容器（墨色描边 + 切角 + 硬投影 + 标题/正文/右对齐按钮同款样式），不再出现系统原生白底圆角弹窗。

### 4.3 预期结果

- 进度条填充可见且随进度变化。
- 草稿确认页正文无重复段落。
- 快速导入 4 个按钮分别进入链接/剪贴板/拍照/手动流程。
- 批量创建后任务列表可见、可逐个操作；一键清空生效且有二次确认。
- 无异常崩溃或英文错误。
