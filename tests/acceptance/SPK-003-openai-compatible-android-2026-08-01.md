## 1. 环境与安全边界

- 平台：Android 模拟器。
- 协议：OpenAI-compatible。
- 模型：DeepSeek-V4-Flash（纯语言模型）。
- 配置方式：只在 App 运行时设置；真实 API 地址和 Key 不进入仓库、命令、Fixture、截图、日志或验收文档。
- 样本：公开风格的人工测试菜谱长正文，不包含个人信息，也不是小红书或抖音固定平台样本。

## 2. 真实主链结果

1. App 能保存非密钥配置并使用安全存储中的 Key 发起真实请求。
2. OpenAI-compatible 连接与文本生成成功。
3. `AI-003` 的受控响应规范化能够处理该纯文本模型返回的有限包装，不放宽严格 JSON Schema。
4. 生成结果进入 `needsReview`，没有自动发布。
5. 草稿写入真实 SQLite；关闭并重新打开数据库后仍可恢复。
6. 至少一个安全错误路径得到稳定、脱敏的错误反馈。

原始 Prompt 和模型完整响应未保存，因此本记录只保留结构化结果和状态结论。
