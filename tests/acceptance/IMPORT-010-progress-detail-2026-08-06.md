# IMPORT-010 解析过程实时显示当前操作详情（progressDetail 全链路）

> 日期：2026-08-06
> 状态：VERIFY（等待项目负责人复测）
> 关联：`解决方案.md`（图片导入体验优化）、`tracking/BACKLOG.md`（IMPORT-010）

## 背景与目标

用户反馈：在解析的时候也要同步当前的信息——例如"获取到了文案""几张图片""是单个
草稿还是多个草稿的""正在弄成草稿的叫什么"。目标是在导入进度页的解析过程中，实时
展示当前正在做什么，而不是只有笼统的"AI 正在逐块拼装你的菜谱"。

实现方式：`ImportTask` 新增 `progressDetail` 展示字段（仅展示，不影响进度校验），
进度回调带可选详情文本，各处理器在关键节点上报，进度页动态显示。

## 前置条件

1. 重新构建并安装 Android 版本（本次有 SQLite schema v11 迁移，**首次启动会自动
   补列，不需要清数据**）。
2. 已在"识图引擎 → 多模态 LLM 图片识别"配置可用的多模态模型（图片转录用）。
3. 已在"LLM 设置"配置可用的菜谱生成模型。
4. 准备：一张含完整菜谱的图片（单图场景）、一个包含 2~3 张每张都是独立完整菜谱的
   多图链接（多草稿场景）、一个普通文本链接或粘贴正文（单草稿快速场景）。

## 复测用例

### 用例 1：单图/多图识别阶段显示"正在识别第 x/N 张图片"

**步骤**：用"拍照选图"或粘贴含多张图片的小红书链接创建导入，在解析过程中观察进度页。

**预期结果**：

- 进入"阶段 3/6 · 识别图片"后，进度条下方动态文案先显示"正在识别 N 张图片中的文字"，
  随后逐张变化为"正在识别第 1/N 张图片"…"正在识别第 N/N 张图片"（N 为实际图片数）。
- 文案实时变化、不与进度条数值矛盾；多图时 N 与日志 `[AIRecipe][Recognize] 单图识别
  耗时=..ms order=..` 的 order 数量一致。

**回传**：进度页识别阶段文案截图或录屏（能看清"第 x/N 张"变化）。

### 用例 2：分组后显示"识别为 N 份独立菜谱，正在生成草稿"

**步骤**：用 2~3 张每张都是独立完整菜谱的多图链接导入。

**预期结果**：

- 识别完成后进入"阶段 5/6 · 生成菜谱"前，文案显示"正在分析 N 张图片是否为同一道菜"。
- 分组判断完成后显示"识别为 N 份独立菜谱，正在生成草稿"（N 与最终多草稿弹窗数量一致，
  也与此前日志 `[AIRecipe][Grouping] 分组结果 … 草稿数=N` 一致）。

**回传**：该阶段文案截图 + 对应 `[AIRecipe][Grouping]` 日志片段。

### 用例 3：多草稿生成时显示"正在生成第 x/N 份菜谱草稿"与完成反馈

**步骤**：同用例 2，继续观察生成阶段。

**预期结果**：

- 生成过程中文案显示"正在生成第 1/3 份菜谱草稿"…"正在生成第 3/3 份菜谱草稿"。
- 每份生成完成时短暂显示"第 x/3 份草稿已生成"，全部完成后显示"全部草稿已生成，正在收尾"。
- 由于并发生成（同时 2 份），文案可能按完成顺序跳变，但不会回退到更小的份数。
- 进入多草稿选择弹窗后，弹窗显示"本次识别到 3 道菜谱"，与生成阶段的 N 一致。

**回传**：生成阶段文案截图或录屏 + 多草稿弹窗截图。

### 用例 4：单草稿场景显示草稿标题

**步骤**：用粘贴正文或单图导入（单草稿），观察生成阶段。

**预期结果**：

- 生成阶段文案依次显示"正在整理识别到的内容，生成菜谱草稿"→"AI 已返回草稿，正在校验
  菜谱格式"→"草稿《<菜名>》已生成，正在保存"（《菜名》为 AI 生成的草稿标题）。
- 进入单草稿确认页后，确认页标题与"正在保存"时显示的菜名一致。

**回传**：生成阶段截图（含《菜名》）或录屏。

### 用例 5：回归——取消/失败/重试后不残留过时详情

**步骤**：任选一个用例，在识别或生成过程中点击"取消解析"；再新建一个导入让它失败
（如断网），观察失败页；对可重试任务点"稍后重试"。

**预期结果**：

- 取消后页面显示"解析已取消"，不显示任何"正在识别/正在生成"的残留文案。
- 失败页显示稳定错误文案，无残留进度详情。
- 重试成功后重新从新阶段的详情开始显示，不出现旧任务的详情。

**回传**：取消/失败状态截图。

## 需要回传的内容

1. 上述各用例的实际结果（通过/失败 + 截图或录屏）。
2. 关键日志片段：`[AIRecipe][Recognize]`、`[AIRecipe][Grouping]`、
   `[AIRecipe][Generate]`（如有）。
3. 若某条文案缺失或与实际不符，请说明出现位置与当时的阶段/进度值。

- iOS 平台（未验证，不阻塞本轮结论）。
